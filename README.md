# 小乔点击工具

一款 Windows 桌面自动点击工具，用于按指定坐标、范围、时间间隔和次数执行自动点击任务。

当前长期维护主线为 WPF 版本，技术栈为 C# / .NET / WPF。

## 适合场景

- 需要在固定位置重复点击
- 需要在一个小范围内随机点击，降低机械重复感
- 需要按固定间隔或随机间隔自动执行点击
- 需要按次数、按时间或手动停止控制任务

## 安装使用

如果你拿到的是安装包：

```text
小乔点击工具 1.1.7.exe
```

直接双击安装即可。

安装说明：

- 默认安装到当前用户目录，不需要管理员权限
- 安装时可选择是否创建桌面快捷方式
- 安装完成后不会自动启动软件，需要从桌面快捷方式或开始菜单打开
- 如果要点击管理员权限运行的软件，请右键“小乔点击工具”，选择“以管理员身份运行”

## 基本操作流程

1. 打开“小乔点击工具”
2. 点击“选择点”
3. 在 3 秒倒计时内把鼠标移动到目标位置
4. 等待工具记录当前坐标
5. 选择点击范围：圆形范围或矩形范围
6. 调整范围大小，默认值为 17
7. 设置点击间隔：固定时间或随机时间
8. 设置停止条件：次数限制、时间限制或手动停止
9. 点击“开始”执行任务
10. 运行中可点击“暂停”“继续”或“停止”

## 快捷键

```text
F6  开始 / 继续
F7  暂停
F8  停止
```

## 功能说明

- 坐标选择：通过 3 秒取点记录鼠标所在位置
- 当前坐标：实时显示当前鼠标坐标，方便确认目标位置
- 圆形范围：在指定半径范围内点击
- 矩形范围：在指定宽高范围内点击
- 固定时间：每次点击使用固定间隔
- 随机时间：每次点击在设定范围内随机等待
- 次数限制：达到指定成功点击次数后自动停止
- 时间限制：达到指定运行时间后自动停止
- 手动停止：用户主动停止任务
- 失败重试：点击发送失败时会重试，失败不计入成功次数
- 高级设置：可查看配置路径、日志目录、最近记录和恢复默认设置

## 数据保存位置

软件会把配置、日志和历史记录保存在本机当前用户目录：

```text
%AppData%\XiaoQiaoClickTool\settings.json
%AppData%\XiaoQiaoClickTool\history.json
%AppData%\XiaoQiaoClickTool\logs\app.log
```

## 注意事项

- 批量点击 1000 次及以上时，建议关闭电脑休眠、锁屏和远程桌面自动断开
- 如果目标软件以管理员权限运行，本工具也需要以管理员身份运行才可能点击成功
- 点击过程中不要随意移动目标窗口，避免坐标位置变化
- 多屏幕和不同 DPI 缩放环境已做适配，但建议首次使用先小次数测试
- 本工具不会把配置、日志或点击记录上传到网络

## 常见问题

### GitHub 页面没有安装包怎么办

仓库默认只保存源码，不保存安装包和发布产物，避免仓库过大。

如需安装包，可以在本地构建后使用 `wpf/installer-wpf.iss` 制作。

### 点击没有生效怎么办

- 确认坐标是否选对
- 确认目标窗口没有移动
- 确认目标程序是否以管理员权限运行
- 尝试右键本工具并选择“以管理员身份运行”
- 先用少量点击次数测试

### 杀毒软件提示怎么办

自动点击类工具可能被部分安全软件重点关注。如果软件来源可信，可以手动放行。正式商业分发时建议使用代码签名证书。
