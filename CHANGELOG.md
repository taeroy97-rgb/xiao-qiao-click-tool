# Changelog

All notable changes to XiaoQiao Click Tool will be documented in this file.

## 1.1.7 - 2026-06-05

### Added

- Public GitHub repository with WPF source code
- GitHub Release installer: `XiaoQiaoClickTool-Setup-1.1.7.exe`
- Root README with screenshot, installation instructions, operation guide, shortcuts, and build instructions
- Visual Studio / .NET solution file: `XiaoQiaoClickTool.slnx`
- MIT License
- Contribution guide and project roadmap

### Included features

- Coordinate picking with a 3-second countdown
- Circle and rectangle random click ranges
- Fixed and random click timing
- Time, count, and manual stop modes
- Pause, resume, and stop controls
- Global shortcuts: F6 start/resume, F7 pause, F8 stop
- Retry handling for failed click delivery
- Local settings, history, and log persistence
- Advanced settings window
- Installer script for Inno Setup

### Notes

- Build outputs, installers, local tool configuration, and generated files are excluded from source control
- The app is designed for local offline use on Windows
