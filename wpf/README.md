这是新的长期维护主线，技术栈为 C# / .NET 10 / WPF。旧 Python、PySide6、WebView 版本只作为参考，不再作为最终产品主线。

不需要下载源码，直接到 GitHub Releases 下载最新版安装包：

https://github.com/taeroy97-rgb/xiao-qiao-click-tool/releases/latest

## 用户安装

如果已经有安装包，直接双击安装：

```text
安装包\小乔点击工具 1.1.7.exe
```

安装说明：

- 默认安装到当前用户目录：`%LocalAppData%\Programs\小乔点击工具`
- 不需要管理员权限安装
- 安装时可选择是否创建桌面快捷方式
- 开始菜单会创建“小乔点击工具”和“卸载 小乔点击工具”入口
- 安装完成后默认不自动启动软件

## 用户操作流程

1. 打开“小乔点击工具”
2. 点击“选择点”
3. 在 3 秒倒计时内把鼠标移动到目标位置
4. 等待工具记录当前坐标
5. 选择点击范围：圆形范围或矩形范围
6. 调整范围大小，默认值为 17
7. 设置点击间隔：固定时间或随机时间
8. 设置停止条件：次数限制、时间限制或手动停止
9. 点击“开始”执行任务
10. 运行中可点击“暂停”“继续”或“停止”

## 快捷键

```text
F6  开始 / 继续
F7  暂停
F8  停止
```

## 主要功能说明

- 坐标选择：通过 3 秒取点记录鼠标所在位置
- 当前坐标：实时显示当前鼠标坐标，方便确认目标位置
- 圆形范围：在指定半径范围内点击
- 矩形范围：在指定宽高范围内点击
- 固定时间：每次点击使用固定间隔
- 随机时间：每次点击在设定范围内随机等待
- 次数限制：达到指定成功点击次数后自动停止
- 时间限制：达到指定运行时间后自动停止
- 手动停止：用户主动停止任务
- 失败重试：点击发送失败时会重试，失败不计入成功次数
- 高级设置：可查看配置路径、日志目录、最近记录和恢复默认设置

## 注意事项

- 批量点击 1000 次及以上时，建议关闭电脑休眠、锁屏和远程桌面自动断开
- 如果目标软件以管理员权限运行，本工具也需要以管理员身份运行才可能点击成功
- 点击过程中不要随意移动目标窗口，避免坐标位置变化
- 多屏幕和不同 DPI 缩放环境已做适配，但建议首次使用先小次数测试
- 本工具不会把配置、日志或点击记录上传到网络

- 浅色玻璃拟态三列主界面
- 小尺寸“选择点”按钮和独立坐标反馈

- 圆形范围 / 矩形范围默认 17，可来回切换，数值支持滑块、手动输入和键盘上下键微调

- 3 秒取点和鼠标跟随 Overlay 预览
- 取点 Overlay 按鼠标所在屏幕 DPI 定位，兼容不同显示缩放和多屏环境
- 配置节流保存到 `%AppData%\XiaoQiaoClickTool\settings.json`
- 日志保存到 `%AppData%\XiaoQiaoClickTool\logs\app.log`
- 全局快捷键：F6 开始/继续，F7 暂停，F8 停止
- 独立高级设置窗口：恢复默认、查看配置路径、打开日志目录、最近 10 条记录，已统一玻璃拟态风格并支持滚动避免遮挡
- 完成后提示音和确认框，确认后自动初始化
- 历史记录保存到 `%AppData%\XiaoQiaoClickTool\history.json`
- `.ico` 图标已由根目录 `logo图标.png` 重新生成，并接入 exe 和安装包

## 常见问题

### 点击没有生效怎么办

- 确认坐标是否选对
- 确认目标窗口没有移动
- 确认目标程序是否以管理员权限运行
- 尝试右键本工具并选择“以管理员身份运行”
- 先用少量点击次数测试

### GitHub 仓库里为什么没有 exe

安装包和发布目录属于构建产物，默认不提交到 GitHub，避免仓库过大。

### 杀毒软件提示怎么办

自动点击类工具可能被部分安全软件重点关注。如果软件来源可信，可以手动放行。正式商业分发时建议使用代码签名证书。
